# 刷题助手 · 三科刷题

数据库原理 / Hadoop 生态（大数据）/ 数据结构 三科合一的自测刷题网页。
单文件、纯前端、离线可用：打开 `index.html` 即可，无需后端与构建。

- 在线地址：<https://12qhj.github.io/quiz/>
- 题库：数据库原理 **257 题**（14 组章节 / 教材第 5 版**全书 16 章**）· Hadoop 生态 **263 题**（教材第 1–14 章）· 数据结构 **171 题**（8 章，严蔚敏第 3 版）
- 数据库原理覆盖王珊《数据库系统概论》第 5 版 **4 篇 16 章**：绪论、关系数据库、SQL、安全性、完整性、关系数据理论、数据库设计、数据库编程、查询处理与查询优化、恢复技术、并发控制、DBMS、技术发展、大数据管理、内存数据库、数据仓库与 OLAP。章节按教材顺序排列，每章都有题与讲义
- Hadoop 模块依据 **林子雨《大数据技术原理与应用——概念、存储、处理、分析与应用》第 3 版**（人民邮电出版社 2021，ISBN 978-7-115-54405-6），覆盖概述、Hadoop 架构、HDFS、HBase、NoSQL、云数据库、MapReduce、Hadoop 再探讨、Hive、Spark、流计算、Flink、图计算、数据可视化
- 题型：单选、判断、多选、填空、序列填空、代码填空、SQL、命令、匹配、排序、简答
- **期末冲刺**：两科都有「期末模拟卷」入口 —— Hadoop 为单选 12 + 判断 8 + 填空 4 + 配对 2 + 简答 4（90 分钟）；
  数据库原理按考纲卷面为选择 12 + 名词解释 6 + 填空 3 + 综合设计 2 + 简答 2（25 题 / 120 分钟）。
  简答题 36 道带「评分要点 + 关键词判分」，判断题 22 道覆盖易混概念
- **数据库原理「考纲对照」页**（按 2026 期末复习大纲整理）：
  - 大纲拆成 **5 个模块 / 29 个考点**，题量、已练题数、正确率全部按题库**实时统计**，补题后自动变化；
  - 每个考点都能一键「练这组」或跳到对应章节讲义；
  - 附 **七大简答必背**（ACID / 选择与投影 / 交并差 / 三类故障 / 完整性 / SQL 分类 / 范式判定）标准答案；
  - 附 **综合题三件套**（E-R→关系模式、建表 SQL、判范式分解），均可判分；
  - 页面顶部明确标注 **「考纲只划重点，不等于教材全部」**，并在 **「考纲之外」** 卡片里自动列出大纲没覆盖的 7 组章节
    （数据库编程、查询优化、DBMS、技术发展、大数据、内存数据库、数据仓库），可直接开练
- 每题标注知识点、难度、分步详解与出处（教材章节 + 官方文档链接）
- **Hadoop 科目的「白话模式」**（为看不懂英文术语的读者准备）：
  - 263 道题每题都有一段 **白话讲解**，用大白话说清「这题问什么、答案为什么」；
  - 题干里的英文术语自动补中文，如「RecordReader（记录读取器）」「Shuffle（洗牌）」；
  - 顶部增加 **术语表** 页，141 个英文词按教材章节分组，支持中英文搜索；
  - 14 章讲义每章开头都有 **「这一章在讲什么」** 的白话导入；
  - 每章讲义含 **「本章重点与难点」**（必须掌握 / 容易卡住 / 一句话记忆）与 **教材图解**（14 张内联 SVG 流程图）；
  - 难度标为「难」的多为参数记忆类题目，标注了「可先跳过」
- Hadoop 题目的出处统一写成 `教材 X.X 节` 形式（如 `教材 3.6.2 写数据的过程`），可直接对到书上的小节
- 进度按科目分别保存在浏览器 localStorage，互不影响

## 部署

`.github/workflows/deploy.yml` 在每次 push 到 `main` 时自动发布到 GitHub Pages
（`actions/upload-pages-artifact` + `actions/deploy-pages`，使用 OIDC，无需令牌）。

首次需要在仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。

## 本地使用

```bash
# 直接双击 index.html，或起一个静态服务
python -m http.server 8080
```
