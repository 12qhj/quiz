# 刷题助手 · 三科刷题

数据库原理 / Hadoop 生态（大数据）/ 数据结构 三科合一的自测刷题网页。
单文件、纯前端、离线可用：打开 `index.html` 即可，无需后端与构建。

- 在线地址：<https://12qhj.github.io/quiz/>
- 题库：数据库原理 **272 题**（14 组章节 / 教材第 5 版**全书 16 章**）· Hadoop 生态 **291 题**（教材第 1–14 章）· 数据结构 **241 题**（8 章，严蔚敏第 3 版；按老师给的卷面题型组织）
- 数据库原理覆盖王珊《数据库系统概论》第 5 版 **4 篇 16 章**：绪论、关系数据库、SQL、安全性、完整性、关系数据理论、数据库设计、数据库编程、查询处理与查询优化、恢复技术、并发控制、DBMS、技术发展、大数据管理、内存数据库、数据仓库与 OLAP。章节按教材顺序排列，每章都有题与讲义
- Hadoop 模块依据 **林子雨《大数据技术原理与应用——概念、存储、处理、分析与应用》第 3 版**（人民邮电出版社 2021，ISBN 978-7-115-54405-6），覆盖概述、Hadoop 架构、HDFS、HBase、NoSQL、云数据库、MapReduce、Hadoop 再探讨、Hive、Spark、流计算、Flink、图计算、数据可视化
- 题型：单选、判断、多选、填空、序列填空、代码填空、SQL、命令、匹配、排序、简答、**算法设计（编程）**
- **期末冲刺**：三科都有「期末模拟卷」入口 —— Hadoop 为单选 12 + 判断 8 + 填空 4 + 配对 2 + 简答 4（90 分钟）；
  数据库原理按考纲卷面为选择 12 + 名词解释 6 + 填空 3 + 综合设计 2 + 简答 2（25 题 / 120 分钟）；
  **数据结构按老师给的卷面为选择 15 + 判断 10 + 填空 8 + 编程 3（36 题 / 120 分钟）**。

## 部署

`.github/workflows/deploy.yml` 在每次 push 到 `main` 时自动发布到 GitHub Pages
（`actions/upload-pages-artifact` + `actions/deploy-pages`，使用 OIDC，无需令牌）。

首次需要在仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。

## 本地使用

```bash
# 直接双击 index.html，或起一个静态服务
python -m http.server 8080
```
